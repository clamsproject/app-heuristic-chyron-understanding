# Heuristic Chyron Understanding

## Description

Prototype to convert chyron text from OCR output (e.g., docTR, Tesseract or a
VLM captioner) into a name and list of attributes, with line-based heuristics:
the first line is the name as written, and the remaining lines are attributes.

### Input and output details

The app takes a MMIF file with `TextDocument` annotations generated by an OCR
app, such as [doctr-wrapper](https://github.com/clamsproject/app-doctr-wrapper),
[Tesseract](https://github.com/clamsproject/app-tesseractocr-wrapper) or a VLM
captioner run with a transcription prompt.
It reads the TextDocuments of the last view that has any, and skips empty texts
and "no text" markers such as `NONE` (an answer some OCR prompts give for a
frame without text).
Blank lines and markdown code fence lines (e.g., "```") around the text are
ignored.

The app outputs a `TextDocument` for each input TextDocument, containing the
text split into `name-as-written`, `name-normalized` and `attributes` fields,
as a JSON string.
The `origins` property of each output points to its input TextDocument (with
`origination` set to `derived`), and `document` is copied from the input.
For more details, see the `output` section of the app metadata.
